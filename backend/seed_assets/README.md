# seed_assets

Opcional. Se deixas imaxes aquí (`.png`, `.jpg`, `.jpeg`, `.webp`), `python -m app.seed`
intenta convertelas a patróns co motor de Persona 2 (`app.engine.convert`).

- Sen motor ou se a conversión falla, o seed funciona igual e ignora estas imaxes.
- Usa imaxes propias ou libres de dereitos.
